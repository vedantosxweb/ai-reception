# Technology Stack

## Core
- **Language:** TypeScript
- **Runtime:** Node.js
- **Framework:** Next.js 16.1.1 (App Router)

## Frontend
- **Styling:** Tailwind CSS 4.0.0
- **UI Components:** Radix UI, Lucide React, Shadcn/UI
- **Animations:** Framer Motion
- **State Management:** Zustand, React Query (@tanstack/react-query)
- **Form Handling:** React Hook Form, Zod

## Backend
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Auth:** Clerk (@clerk/nextjs) and NextAuth.js (v5 beta)
- **Background Jobs:** BullMQ with Redis (ioredis)
- **Validation:** Zod
- **Webhooks:** Svix

## Infrastructure & AI
- **LLM Providers:** OpenAI, Anthropic, Google Generative AI (Gemini)
- **Speech Services:** Deepgram (STT), ElevenLabs (TTS), PlayHT (TTS)
- **Vector Database:** Pinecone
- **Monitoring:** Sentry
- **Communications:** Twilio, Telnyx, Resend
- **Billing:** Creem.io (SaaS billing via Stripe)
