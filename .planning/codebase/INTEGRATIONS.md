# External Integrations

## APIs & Services
- **OpenAI:** Primary LLM and voice capabilities.
- **Anthropic:** Alternative LLM provider (Claude).
- **Google Generative AI:** Gemini models integration.
- **ElevenLabs:** Advanced text-to-speech for custom voices.
- **PlayHT:** Real-time text-to-speech engine.
- **Deepgram:** High-performance speech-to-text.
- **Twilio:** Primary SMS and Voice telephony.
- **Telnyx:** Secondary/Alternative telephony provider.
- **Resend:** Transactional email services.
- **Svix:** Webhook management and security.
- **HubSpot:** CRM integration for lead management.
- **Salesforce:** Enterprise CRM integration (detected in schema).
- **Google Calendar:** Scheduling and appointment management.
- **Frankfurter:** FX rates API for currency conversion.

## Databases & Storage
- **PostgreSQL:** Primary relational database (accessed via Prisma).
- **Pinecone:** Vector database for RAG and knowledge base.
- **Redis:** Distributed task queue (BullMQ) and caching.

## Auth & Security
- **Clerk:** User authentication and management.
- **NextAuth.js:** Secondary authentication layer.
- **Sentry:** Error tracking and logs monitoring.
